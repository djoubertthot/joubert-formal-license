## How to apply it to a repository

1. Copy `LICENSE.md` and `COPYING.interpretation` to the **root**.
2. Put this header at the top of each source / article file:

```
Copyright © 2026 Denis Joubert.
This file may be distributed under the GNU GPL v3 or later,
or the Creative Commons Attribution-ShareAlike 4.0 International
License, subject to the binding interpretation in
LICENSE.md (section 3).
```

3. On GitHub, **About \u2192 License** will often show *Other*. That is expected:
   this is a dual license plus an interpretation, not a single SPDX identifier.
